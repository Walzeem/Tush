# Tush Wallet — Frontend (`dashboard/`)

React 19 + TypeScript + Vite frontend for **Tush Wallet**. See the root [README.md](../README.md) for full architecture, backend setup, and API documentation.

## Quick Commands

```bash
npm install        # Install dependencies
npm run dev        # Start Vite dev server
npm run typecheck  # Run TypeScript check (tsc --noEmit)
npm run lint       # Run ESLint
npm run build      # Typecheck & build production bundle
```
